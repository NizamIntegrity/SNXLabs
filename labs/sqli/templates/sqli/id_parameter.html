🛡️ Remediation

Bind the ID as a parameter

Use a prepared, parameterized statement so the ID remains a value and cannot change SQL syntax.

query = "SELECT id, name, price FROM products WHERE id = ?"
products = connection.execute(query, (product_id,)).fetchall()

Validate expected input too

Check that an ID has the expected format and range for clear application behavior. Validation helps, but does not replace parameter binding.

Use limited database access

Keep the database account and file permissions limited to what the application needs. Return a generic error to users and keep detailed SQL errors in protected server logs.
