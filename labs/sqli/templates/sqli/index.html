🛡️ Remediation

SQL Injection occurs when untrusted user input is directly concatenated into an SQL query.

In this lab, the vulnerable application builds the query by inserting the username and password directly into the SQL statement.

❌ Vulnerable Code 
query = (
    "SELECT * FROM users "
    f"WHERE username = '{username}' "
    f"AND password = '{password}'"
)

results = connection.execute(query).fetchall()

The problem is that the application treats user input as part of the SQL syntax.

✅ Secure Code 
query = (
    "SELECT * FROM users "
    "WHERE username = ? "
    "AND password = ?"
)

results = connection.execute(
    query,
    (username, password)
).fetchall()

The ? placeholders tell SQLite to treat the supplied values as data rather than SQL syntax.

  • Use parameterized queries instead of string concatenation.
  • Validate input where appropriate.
  • Use least-privilege database accounts in production.
  • Avoid exposing database errors directly to users.
